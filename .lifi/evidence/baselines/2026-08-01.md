## Current Website Audit architecture

- Public intake and status: Netlify Functions under `/examples/audit/`
- Report, job, rate-limit, view, and engagement state: Netlify Blobs
- Durable production follow-up: Netlify Database with bounded retention
- Site analysis: Google PageSpeed with a deterministic fallback
- AI analysis: Anthropic through Netlify AI Gateway only
- Delivery: Google Workspace Gmail API using server-side OAuth credentials
- Scheduled cleanup: expired Blobs and database rows are removed by the daily
  cleanup function

The production path has no Notion CRM write, mailbox-password SMTP flow,
Twilio voice intake, Supabase lead schema, Resend delivery, direct OpenAI API
call, or direct Anthropic endpoint. Public editorial pages may still discuss
third-party products; product commentary is not integration code.

## Repository and account boundary

- The production website tree is `app/`; live server code is `netlify/`.
- Legacy static trees, standalone Audit checkouts, repo-local agent packs, and
  Claude Code GitHub workflows are retired.
- Regression gates run before every application build and reject retired
  provider plumbing, duplicate root website trees, and stale local context.
- Git history is retained without rewriting. Legacy branches, old public
  deploy permalinks, dangling DNS aliases, and obsolete OAuth clients are not
  active recovery or production surfaces.
- Secret values, production submissions, and private provider payloads are not
  repository evidence and must never be copied into this tree.

## Release and external evidence

`npm run quality:release` is the required local production-candidate gate.
After the exact Git deploy is ready, `EXPECTED_REVISION=<commit> npm run
quality:live` must pass against production. Routine verification does not send
a real form submission or email; end-to-end inbox proof remains an explicitly
authorized external test.

Open research, proof-approval, backup-owner, social-preview, and external
delivery gates remain recorded in `.lifi/debt-and-exceptions.yml`.
